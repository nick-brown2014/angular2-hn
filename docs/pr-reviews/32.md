# PR Review Log #32

## Review — Angular 9 → React (Vite + TS) migration

## Summary
- **Scope**: Full frontend rewrite (Angular 9 → React 18 + Vite + TypeScript + react-router-dom), preserving features/UX. Data layer, settings, routing, components, SCSS theme engine, and PWA all ported.
- **Risk**: Medium — large surface, but the port is faithful and structurally clean; concerns are localized.
- **Positives**:
  - Data layer cleanly converts RxJS `lazyFetch` → `async/await` + `AbortController`; poll aggregation logic preserved verbatim.
  - Settings singleton → Context + `useSettings` with localStorage keys and `prefers-color-scheme` listener intact.
  - Routing, lazy `ItemDetails`/`User`, recursive `Comment` collapse, and pagination math (`(page-1)*30+1`) faithfully reproduced.
  - SCSS theme engine reused; manifest/icons/PWA (Workbox) preserved; `firebase.json` correctly serves `dist/`.

- **Concerns** (see inline):
  1. **[major]** Theme flash on load — saved theme not read at init (`SettingsContext.tsx:28`); regression vs Angular's synchronous `initTheme`. Also flagged by Devin Review.
  2. **[major]** No Node pin/`engines` — Vite needs Node 20+ but repo targeted Node 14; fresh checkouts/CI will hit cryptic failures (`package.json`).
  3. **[major]** `dangerouslySetInnerHTML` drops the sanitization Angular's `[innerHTML]` provided (4 sites: comment, poll, item content, user about). Low real-world risk given node-hnapi output, but loses defense-in-depth.
  4. **[minor]** `getJson` ignores `res.ok`, so HTTP errors don't reliably trigger the error UI (`hackerNews.ts:10`).
  5. **[minor]** Google Analytics pageview tracking (old `AppComponent` NavigationEnd → `ga`) was dropped and not re-implemented — confirm this is intentional feature removal.
  6. **[nit]** `react-refresh/only-export-components` lint warning: `SettingsContext.tsx` exports both the provider and the `useSettings` hook.
  7. **[nit]** Poll options fetched sequentially (`await` in loop) vs. the original's concurrent requests — slightly slower for multi-option polls; correct otherwise.

## Decision
**Request changes** — the theme-flash regression (1) and missing Node pin (2) are worth addressing before merge; the sanitization note (3) needs at minimum an explicit decision. Everything else is minor/nit.

## Next steps

2. Add `.nvmrc` (`20`) + `engines.node >= 20`, and set the new CI to Node 20.
3. Decide on HTML sanitization (add DOMPurify or document the accepted-raw-HTML decision).
4. Add a `res.ok` guard in `getJson`.
5. Confirm dropping Google Analytics is intended.
